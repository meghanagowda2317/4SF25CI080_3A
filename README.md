# Medical Dataset Analysis

## Overview

This project analyzes a medical dataset using Python, Pandas, and Matplotlib. The analysis includes data understanding, data transformation, handling missing values, insight generation, and data visualization.

## Dataset

The dataset used for this project is `Medicaldataset.csv`.

The dataset contains information such as:

- Age
- Gender
- Heart rate
- Systolic blood pressure
- Diastolic blood pressure
- Blood sugar
- CK-MB
- Troponin
- Result

## Data Processing

The following operations were performed:

- Read the CSV dataset using Pandas
- Studied the structure and contents of the dataset
- Checked data types
- Checked for null values
- Handled numerical null values using mean imputation
- Converted the Result column to categorical type
- Created a new `Age Group` column
- Generated meaningful insights from the data

## Data Visualization

The project contains visualizations for:

- Medical result distribution
- Patients by age group
- Average heart rate by medical result
- Average blood sugar by medical result
- Age vs Heart Rate
- Age vs Blood Sugar
- Average blood pressure by medical result
